# Algorithmic Assessment Rules

- **Approach First:** Always present the time/space complexity (Big-O) and approach high-level breakdown BEFORE providing any code solution.
- **Edge Cases:** Proactively list potential edge cases (e.g., empty inputs, overflow, single elements, nulls, negative numbers).
- **Test Generation:** Whenever a solution is requested, immediately generate a suite of unit tests (including normal cases and edge cases).
- **Code Quality:** Write clean, highly readable production-grade code. Keep functions modular.
